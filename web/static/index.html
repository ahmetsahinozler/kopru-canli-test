Kayıtlı bilgisayarlar

Henüz kayıtlı bilgisayar yok. Bağlandığınızda burada görünür.

Bu bilgisayarı uzaktan erişime aç

Windows bilgisayarda Köprü'yü indirip çift tıklayın. Kimlik ve parola otomatik oluşur; sunucu ayarı gerekmez.

Windows için Köprü'yü indir

Program imzalı olmadığı için ilk açılışta Windows "Windows bilgisayarınızı korudu" diyebilir: Ek bilgi → Yine de çalıştır. Microsoft Defender uzaktan erişim programlarını "istenmeyebilecek uygulama" sayıp engelleyebilir; o zaman Windows Güvenliği → Virüs ve tehdit koruması → Koruma geçmişi'nden İzin ver. Kalıcı ve oturum açma ekranı dahil erişim için açılan pencerede Hizmet olarak kur'a basın.

Bağlanıyor…
Uzun sürüyor. Bilgisayar kapanmış, uykuya geçmiş ya da interneti kesilmiş olabilir; Köprü beklemeye devam ediyor. Bilgisayar açıksa biraz daha bekleyin, değilse Vazgeç'e dokunun.
